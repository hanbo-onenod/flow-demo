## Goal

Exporting the order report to CSV is too slow: about 5 seconds for 10,000 orders. Operations and finance export it every week for reconciliation, and several overseas customers have complained. Make it fast enough that 10,000 orders export in under 1 second. Wanted within this week (by 2026-11-08).

## Scope

- In: speed of the order report CSV export (`app/export_report.py` and the database access it uses in `app/db.py`).
- Out: the CSV's columns, row order, values and encoding stay exactly as they are today (no UTF-8 BOM change); no date filter; no Excel export; no other reports.

## Acceptance criteria

- Exporting 10,000 orders takes under 1 second, measured with `python scripts/bench_export.py`.
- The exported CSV content (header, rows, order, formatting) is identical to the current output for the same data; existing tests pass (`pytest tests/test_export.py`).
